# Clean-room policy

Nera is an independent browser. Its ideas (vertical tabs, Spaces, a command bar) are common across browsers, and its
code, design, text and assets are its own.

## Rules for every contribution

- **No code from closed-source browsers,** in any form: copied, translated, decompiled or paraphrased.
- **No assets or text from other products:** names, logos, icons, sounds, fonts, illustrations, onboarding copy, UI
  strings or color presets.
- **Original design.** Layouts can follow common conventions; visuals are our own.
- **Interoperability is fine:** reading the data files people export or keep from other browsers so they can import
  them, and following widely used conventions such as standard keyboard shortcuts.
- **Respect licenses:** code from open-source projects only under a compatible license, with its notice.
- Never circumvent licensing, DRM or other technical protection measures.

Features are implemented from public platform documentation and our own written descriptions of the behavior we
want. Pull requests that don't follow these rules are closed.
